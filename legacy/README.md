# Legacy

Material from the earlier agentic RAG pipeline (LangGraph, GROBID, figure extraction) that was
evaluated on machine-learning research papers. It is kept for reference only and is **not
maintained** — the current system lives in `rag_core.py`, `app.py` and the notebooks in the
repository root.

| Path | Contents |
|---|---|
| `agentic_rag_chatbot.ipynb` | Original agentic chatbot (requires Docker + GROBID for PDFs) |
| `automated_evaluation.ipynb` | Evaluation of the agentic chatbot on ML papers |
| `evaluation_pdfs/` | Dataset and results for the ML-paper evaluation, plus `diagrams.ipynb` |

Run notebooks from the repository root so relative paths resolve.
